# `api` plugin

API development — FastAPI, SQLAlchemy and Domain-Driven Design with Hexagonal Architecture.

## Skills

| Skill | Description |
|---|---|
| `ddd` | Domain-Driven Design with Hexagonal Architecture (Ports & Adapters). |
| `fastapi` | FastAPI best practices with Pydantic v2 for production REST APIs. |
| `sqlalchemy` | SQLAlchemy v2 best practices for ORM, Core, and migrations. |

## Agents

| Agent | Description |
|---|---|
| `api-reviewer` | Scans the API for vulnerabilities, RBAC leaks and compliance issues. |
