# `api` plugin

API development — FastAPI, SQLAlchemy and Domain-Driven Design with Hexagonal Architecture.

## Skills

| Skill | Description |
|---|---|
| `ddd` | Domain-Driven Design with Hexagonal Architecture (Ports & Adapters). |
| `fastapi` | FastAPI best practices with Pydantic v2 for production REST APIs. |
| `sqlalchemy` | SQLAlchemy v2 best practices for ORM, Core, and migrations. |

## Agents

| Agent | Description |
|---|---|
| `api-reviewer` | Read-only API security review (vulnerabilities, RBAC leaks, compliance) that posts a verdict with severities; a driver fixes what it finds. |

## Install

```bash
# Claude Code / Copilot CLI / Codex (codex plugin add)
/plugin install api@giocaizzi-harness
```

Every harness (Codex, opencode and pi included), updates and local development: [docs/install.md](../../docs/install.md).
