# `infra` plugin

Infrastructure as code and containers: Terraform and OpenTofu, Docker images, Kubernetes manifests, Helm charts and operators.

## Skills

| Skill | Description |
|---|---|
| `terraform` | Terraform and OpenTofu: layout, plan and apply in CI, state, modules, tests. |
| `docker` | Dockerfiles, images and compose: multi-stage builds, cache, non-root, supply chain. |
| `kubernetes` | Kubernetes manifests, Helm, Kustomize and operators: workload defaults, RBAC, rollout, delivery from CI or GitOps. |

## Install

```bash
# Claude Code / Copilot CLI / Codex (codex plugin add)
/plugin install infra@giocaizzi-harness
```

Every harness (Codex, opencode and pi included), updates and local development: [docs/install.md](../../docs/install.md).
