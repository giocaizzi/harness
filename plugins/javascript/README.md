# `javascript` plugin

JavaScript and TypeScript development — ES6+, Node.js, React and Next.js.

## Skills

| Skill | Description |
|---|---|
| `javascript-typescript` | TypeScript and Node.js on the Google TypeScript Style Guide: TS 7, Node 26 LTS, pnpm, ESLint 10, strict tsconfig, design. |
| `typescript-testing` | Vitest tests: table tests, fakes over mocks, fake timers, MSW, fast-check, snapshots. |
| `react` | ReactJS development standards and best practices. |
| `nextjs` | Next.js best practices and conventions. |
| `atomic-design` | Atomic design for the UI kit and lint rules that enforce component architecture. |

## Install

```bash
# Claude Code / Copilot CLI / Codex (codex plugin add)
/plugin install javascript@giocaizzi-harness
```

Every harness (Codex, opencode and pi included), updates and local development: [docs/install.md](../../docs/install.md).
