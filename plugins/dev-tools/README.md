# `dev-tools` plugin

General development tooling — git, GitHub, conventional commits, semantic versioning, automated releases.

## Skills

| Skill | Description |
|---|---|
| `conventional-commits` | Conventional Commits 1.0.0 — type, scope, breaking change, and bump semantics. |
| `semver` | Semantic Versioning 2.0.0 — choosing major, minor, and patch from compatibility impact. |
| `release-please` | Automated versioning, changelog, and tagging from Conventional Commits. |

## Install

```bash
# Claude Code / Copilot CLI
/plugin install dev-tools@giocaizzi-skills
```

See the [repository README](../../README.md) for marketplace setup and local-development instructions.
